# orbita-market-autotests

Автотесты для проекта **orbita-market**

Набор автотестов для проверки REST API системы
**[orbita-market](https://github.com/tdutanton/orbita-market)**.  
Проверяет корректность обработки запросов, валидность ответов и соблюдение контракта эндпоинтов.

Автоматизированы тестовых сценариев, указанных в ТЗ на разработку:

- Счет -> Пополнение -> Заказ на корректную сумму;
- Заказ на сумму, больше чем баланс пользователя;
- Попытка повторной оплаты по одному и тому же id заказа;
- Корректное создание двух заказов (общая стоимость ниже баланса пользователя);
- Попытка создания еще одного счета для пользователя.

Также созданы автотесы для каждого предусмотренного ТЗ REST-эндпоинта **orbita-market**:

1. **Orders-service**:
    - POST /orders - создать заказ
    - GET /orders - получить данные о заказах по id пользователя
    - GET /orders/{order_id} - получить данные о заказе по id пользователя и id заказа

2. **Payments-service**:
    - POST /accounts - создать счет для пользователя
    - POST /accounts/top-up - пополнение счета пользователя
    - GET /accounts/balance - получить баланс пользователя

## Запуск

Тесты можно запустить двумя способами:

- с консоли или IDE через gradle;
- при помощи Docker.

### Через gradle

Порядок запуска тестов:

1. Запустить сервис orbita-market (дополнительно про запуск сервиса указано в **README.md** в
   репозитории orbita-market):  
   Находясь в репозитории orbita-market выполнить команду

```bash
docker compose up -d
```

Команда запустит необходимые для работы **orbita-market** контейнеры.

2. Запустить тесты в этом репозитории:

*Удобнее запускать через IDE*

Только тесты:

```bash
gradle test
```

Или

```bash
gradle cleanAndTest
```

для повторного запуска (в случае появления сообщения "Test events were not received" из-за
кеширования gradle).

Allure отчет:

```bash
gradle allureServe
```

Запустить сразу и тесты и открытие Allure отчета (пользовательская цель сборки добавлена в
build.gradle.kts):

```bash
gradle cleanAndTestAndReport
```

Если возникают ошибки при запуске команд - попробуйте запуск через **./gradlew ...** (для создания
gradlew - **gradle wrapper --gradle-version 8.5**).

Чтобы увидеть возможные цели для сборки (в случае конфликтов с gradle):

```bash
gradle -b build.gradle.kts tasks --all
```  

### Через Docker

Можно запустить тесты через docker.  
Для этого должен быть запущен orbita-market через Docker.  
Далее запускаем контейнер, находясь в репозитории тестов:

```bash
docker compose up
```  

Если запуск на Linux выдает ошибку - попробуйте через *sudo*.

В контейнере будут запущены тесты с выводом результатов в консоль.  
После тестов будет создана папка **test-reports**, где будет лежать отчет о проведенном
тестировании (файл *index.html*)
